# Đánh giá trên bộ dữ liệu mới

Chọn ít nhất một bộ dữ liệu phù hợp mà paper chưa sử dụng. Mô tả lý do chọn, liên kết hướng dẫn chuẩn bị trong [data/](../../data/README.md), và giải thích cách chuyển dữ liệu sang đầu vào mà mô hình cần.

Lưu cấu hình, lệnh chạy, chỉ số phù hợp với nhãn, kết quả định lượng và ví dụ thành công hoặc thất bại. Ghi rõ cách giữ tập test độc lập trong quá trình chọn mô hình hoặc tinh chỉnh. Nếu dữ liệu hoặc giao thức khác paper, giải thích ảnh hưởng của khác biệt đó khi thảo luận số liệu.
